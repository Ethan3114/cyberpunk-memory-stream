## 街道分层到底做什么

近处立柱、招牌移动较多，远处街道和高楼移动较少，让鼠标响应具有距离差；滚动时也可以让近景先放大、经过镜头，带出向街道内部推进的感觉。这是受控的空间近似，不能转头看整条街。

图片完全可以通过 AIGC 制作。本批采用“原创完整底图 + 独立生成透明装置”，不是把同一张整图复制三次；底图完整，装置移动时不会揭出抠图空洞。后续若选择游戏街道，则需要对那张真实画面另做提取、补全与配准。

视频适合雨、雾、霓虹和反射变化；单条视频的预渲染视角不能自动响应用户鼠标。滚动可以映射播放时间，但seek和反向滚动需实测。[MDN媒体播放时间说明](https://developer.mozilla.org/en-US/docs/Web/API/HTMLMediaElement/currentTime)

当前推荐先用图片分层确认空间构图，再考虑固定机位的image-to-video背景，并保留静态首帧、透明前景与独立HTML文字。当前工具没有视频生成能力，本批未生成视频；可执行视频简报在street-aigc/production-notes.md。
