# 第九版：地面、点云旋转与共同下降

2026-10-11。按用户两张对比截图及随后的旋转补充修正开场。

## 原因和修正

旧实现把原点云锁在入口 funnel 姿态，低处点被抬到上空；世界距离上的回避半径未适配 .43 模型缩放。地面距离衰减还隐藏了靠近镜头的点，因此底部空白，下降后更加稀疏。相机锁定也与用户要求的共同下降不符。

- 保留原 65536 点、源气泡材质及 GPU 鼠标流场。使用恒定的 settled pose（uScroll=1），避免滚动时粒子整体下沉或淡出；低处点不受中心下凹影响。
- 原地面点的 X/Z 范围扩大至 1.4 倍，在树根到树冠之间平滑过渡，形成近、中、远的地面覆盖。地面独立使用 1.1–3.6 世界单位的距离尺寸衰减；树冠保留 8–15 衰减以保持字标可读。地面不使用中心空管剔除；字标回避范围适配模型缩放。没有增加额外粒子数量或新增地面贴图。
- 点云 Y 和 Z 保持 −2.8 / −3，随 .00–.20 滚动旋转 190°；第一幕在 .20 结束前不因滚动降低 opacity 或点数。
- 相机初始 [0,.64,12.05]，按原场景相机比例设置轻微俯视；镜头和字标使用相同 1.8×smooth(.02,.18,p) 下降，镜头高度始终比字标高 .64。字标自己的偏航/侧背面旋转保留。
- 模糊视频仍在固定世界平面。斜向切幕的下一环境使用独立 [0,0,10] 镜头，完成时与正式环境镜头一致，避免下降带偏下一幕。
- 鼠标流场方向转换为旋转点云的局部坐标，并保留原局部单位强度；旋转后上下浮动仍与屏幕方向对应。

本地原站代码依据：`research/active-theory/live-app.js` 的 Home 更新中，camera.group.position.y 随滚动变化，logo.position.y 跟随相机组；点云 group.rotation.y 含 −190°×scrollProgress。本项目使用已确认的开场时段和自身空间比例，未声称恢复原站完整相机时间线。shader 来源为 [原站 compiled.vs](https://activetheory.net/assets/shaders/compiled.vs)。

- progress 0 → .10：相机 Y .640 → −.260，字标 Y 0 → −.900；两者同降 .900，Z 均不变。点云绕轴转 95°，平移与缩放不变，视频平面矩阵一致。两处点数均 65536。
- `opening-ground.png` / `descending.png`：初始和旋转下降中段的实际画面，近处地面延伸至底部；不再是底部整体无粒子。源森林仍有自然疏密，未将它变成均匀二维点阵。
- `transition.png`：progress .15 的实际斜向切幕，固定世界视频、旋转点云和跟随字标的镜头构成上方空间；下方官方街道由独立镜头渲染。切幕遮罩有意逐渐揭示下一幕，不作为点云稀疏缺陷。
